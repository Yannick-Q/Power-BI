# Home & Lifestyle Retail Group – Performance & Insights Report

IHK-Abschlussprojekt (Gruppenarbeit): interaktiver Power-BI-Report zur 
Analyse von Vertriebs-, Produkt- und Kundendaten einer fiktiven 
Retail-Unternehmensgruppe.

**Team:** Axel Heilemann, Hong Ngan Ngo, Yannick Quast

## Enthaltene Dateien
- `Home_&_Lifestyle_Retail_Group_YQ.pbix` – finaler Power-BI-Report
- `HLRG_IHK_Präsentation.pptx` – Präsentation zur IHK-Abschlussprüfung

## Report-Struktur
Management Overview · Product Analysis · Yearly Performance · 
Sales Analysis Region & Channel · Customer Value & Loyalty · 
Anomaly Analysis · What-If Analyse

## Verwendete Tools & Methoden
- Power BI (Power Query, DAX, Sternschema-Datenmodell)
- Zeitintelligenz, statistische Kennzahlen (Median, Standardabweichung, 
  Variationskoeffizient), RFM-Segmentierung
- What-If-Parameter für Szenarioanalysen
