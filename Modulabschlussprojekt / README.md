# FC 26 Spieleranalyse – Power BI Modul-Abschlussprojekt

Individuelles Abschlussprojekt im Rahmen des Moduls: Analyse eines 
FC-26-Spielerdatensatzes (~18.400 Spieler) mit Fokus auf Länder- und 
Attributvergleiche.

## Enthaltene Dateien
- `Abschlussprojekt_YQ_Fifa_Players.pbix` – finaler Power-BI-Report
- `Praesentation_Abschlussprojekt_YQ.pptx` – Präsentation

## Report-Struktur
Navigationsseite · Übersicht · Altersanalyse · Potenzial Ausreißer · 
Länderdetails · Attributsanalyse · Szenarioanalyse · Land-Detailansicht · 
Bonus: Bester Spieler (inkl. Quickinfo-Tooltipseiten für Land und Kontinent)

## Verwendete Tools & Methoden
- Power BI (DAX, Datenmodellierung)
- Azure Maps für Länderdarstellung
- What-If-Parameter für Szenarioanalyse
